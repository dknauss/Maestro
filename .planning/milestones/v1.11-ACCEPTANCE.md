**For:** Dan, by hand, on the final 1.11 build (main after Phases 32–35 merge,
or the 1.11.0 release candidate). Automation and browser emulation have
already run; these are the checks only a person on real hardware can make.

**Where:** the main-build Playground (`playground/blueprint-hosted.json` on

**Record once at the top of your notes:** date, Maestro commit or version,

## 1. iPad (Safari), portrait and landscape

- [ ] Enter edit mode from the admin bar, then exit and re-enter.
- [ ] Tap through every toolbar control. Targets are easy to hit, nothing wraps
      badly, and the menu doesn't close by accident.
- [ ] Rename an item using the on-screen keyboard. The field and toolbar stay
      above the keyboard; tapping another row commits the name.
- [ ] Open Visibility, the icon picker, Visibility groups and Preview as. Long
      content scrolls inside the sheet, the page behind it doesn't, and Close
      works.
- [ ] Create a visibility group, add and remove a person, assign it, reload.
- [ ] Tour: Next, Back, Close and Done; every tip stays on screen.
- [ ] Width (landscape, 961px and wider only): drag the edge handle and use the
      slider. Save, reload, and the width holds.
- [ ] Settings › Export, then Import that file back (desktop widths only).

## 2. New in 1.11, on iPad and on a desktop browser

- [ ] **WordPress icons:** open the icon picker on a top-level item, choose the
      WordPress tab, search "store", pick it. The icon shows in the menu in
      the scheme's colours (it lightens on hover), survives reload, and the
      picker reopens on the WordPress tab. Judge whether core's icons look too
      small beside Dashicons.
- [ ] **Separators:** select a separator. Focus lands on ▲, not Remove. Try
      moving a separator to the bottom, or an item so two separators touch: it
      refuses and says why. Switch to the Light colour scheme: the separator
      line is visible in edit mode. The Add and Remove separator buttons are
      icons only, with tooltips.
- [ ] **Saved check (desktop):** make a change. "Saved" floats up, fades, and a
      muted ✓ stays in the toolbar (tooltip "All changes saved") until the next
      change.

## 3. VoiceOver (macOS Safari, then iPadOS)

- [ ] Each save is announced **once** ("Saved"), not twice.
- [ ] A refused separator move is announced with its reason.
- [ ] A separator row is read as "Separator", and the ▲ button it focuses has a
      clear name.
- [ ] Icon picker: tabs are announced as tabs with their names (Dashicons,
      Bootstrap, WordPress); icon cells read their labels; arrow keys move
      through cells.
- [ ] Visibility: "All other roles" announces mixed when partly selected and
      names its section; a locked child row explains why.
- [ ] Person picker: search results, adding a person and removing their chip
      are all announced.
- [ ] Settings › Import: the review report and "Configuration imported" are
      read out.
- [ ] Preview as: the read-only banner and Exit preview are reachable and
      named.

### Found and fixed

1. **iPad Safari zoomed the page when a text field took focus.** At 783px
   and wider (every iPad except the mini upright) the rename field was 13px
   and the dialog fields 14px; iPadOS zooms on focus below 16px, which throws
   the toolbar and dialogs off screen as the keyboard opens. Touch screens
   now get 16px fields at every width (`pointer: coarse`).
2. **Toolbar buttons were 36px tall on iPads.** Touch screens now get 44px
   tall buttons at every width. Width stays 40px so a 1024px iPad's toolbar
   keeps one row.
3. **The width edge handle was 8px wide** for a finger. On touch screens
   its hit area is now 24px, reaching over the page rather than the menu
   rows, with the painted strip unchanged. A drag now starts from where the
   finger lands instead of jumping the edge to it.

### Dan's hardware script (about 15 minutes)

Use the main-build Playground after the fixes merge. iPad first, then the
Mac.

1. **iPad Safari, landscape.** Enter edit mode, tap Posts, tap the name
   field. The page must not zoom, and the toolbar should ride above the
   keyboard. Type a name, tap Media: the name sticks.
2. Open the icon picker, tap its search field (no zoom), pick WordPress ›
   "store". Judge the size beside Dashicons. Tap outside to close it; the
   menu stays open.
3. Drag the menu's right edge with a finger. It should be easy to grab and
   not jump. Reload; the width holds.
4. Open Visibility groups, create a group, add and remove a person, then
   close. Watch for the keyboard covering the field or Close, and for the
   page scrolling behind the sheet.
5. **Rotate to portrait** and repeat step 1 and one dialog. Run the tour
   once by tapping through.
6. **VoiceOver on the iPad** (triple-click the top button if it's set as the
   shortcut). Rename an item and hear "Saved" once. Open the icon picker and
   swipe through the tabs (should say "tab"). Close it with the two-finger
   scrub (a quick Z). If the scrub doesn't close it, note that, since
   Icons and Visibility have no Close button on the iPad layout.
7. **VoiceOver on the Mac, Safari** (Cmd+F5). Rename and hear "Saved" once.
   Select a separator and press ▼ until it refuses: you should hear why.
   Open Visibility, tick one role, and hear "mixed" on All other roles.
   Start Preview as, then reach Exit preview with VO+Right.

Anything that fails: note the step number in the table below.
