<objective>
Add the optional per-parent "cascade hide to children" behavior (COMPAT-10),
default OFF, as a pure visibility computation layered on the existing
`hidden_roles` semantics — never touching capabilities. When a parent is hidden
for a role and its cascade flag is on, all live children under it are
cosmetically hidden for exactly those roles.

Purpose: Today hiding a parent orphans the subtree cosmetically but every child
stays in the sidebar; an admin who wants the whole subtree gone has no switch.
This adds that switch while holding Maestro's hard cosmetic-only guarantee.
Output: A cascade flag in config, a pure role-mirrored/union cascade computation
wired into replay child-visibility, model exposure of the flag, and an explicit
cosmetic-only guardrail test. Editor UI + e2e are 20-06.
</objective>
