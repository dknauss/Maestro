<objective>
Preserve badge / HTML-in-title markup on rename (COMPAT-07). Instead of writing
the stored title wholesale over `$menu[pos][0]` / `$submenu[parent][pos][0]`,
replace only the human-readable text node(s) in the LIVE rendered title, keeping
the markup before AND after the label. Storage stays plain text; the badge HTML
never enters the config.

Purpose: 4/6 R1 plugins bake HTML into titles — trailing count spans
(WooCommerce/Yoast) and wrapping spans (WPForms `<span>Addons</span>`, Yoast
upsell). Today's wholesale overwrite strips them. This restores them while keeping
the cosmetic, non-destructive, resolve-time contract.
Output: A pure text-node replacement helper (unit-tested against the fixture
shapes) wired into both replay title-write seams, with a wholesale fallback for
no-text-node titles.
</objective>

Replay::replay() writes titles wholesale today:
```php
$menu[ $pos ][0] = $ovr['title'];                 // ~L134 (top-level)
$submenu[ $parent ][ $pos ][0] = $ovr['title'];   // ~L188 (submenu)
```

Editor already edits plain text only — get_menu_model() strips tags for display:
```php
'title' => isset($row[0]) ? wp_strip_all_tags($row[0]) : '',   // ~L439, ~L452
```
Config::sanitize() runs sanitize_text_field on stored titles (~L164). So the stored
custom label is ALREADY plain text; this plan changes only how it is re-applied.

Locked (20-CONTEXT.md):
- Text-node replacement preserving markup BEFORE and AFTER the label (not a trailing-suffix split).
- Markup re-extracted from the LIVE title each request at replay; badge HTML NEVER stored.
- No-text-node fallback = wholesale set (today's behavior).
- Helper-vs-inline is executor discretion; a dedicated pure helper is preferred for unit coverage.

Fixture title shapes to cover (from BACKLOG COMPAT-07):
- Trailing count bubble: `Orders <span class="awaiting-mod count-3"><span class="pending-count">3</span></span>`
- Notification span (Yoast): `SEO <span class="update-plugins count-1">…</span>`
- Wrapping span (WPForms Addons): `<span style="color:#f18500">Addons</span>`
- Upsell wrapper (Yoast/Elementor): label wrapped or followed by an upsell `<span>`/`<div>`.
- Plain label (no markup): unchanged behavior.
- No-text-node (icon + empty spans only): wholesale fallback.
