<objective>
Establish what is actually left of this phase before implementing anything.

Purpose: the phase was scoped 2026-08-02 from a defect report, and **two of its
five criteria have already decayed** — one was silently fixed, another rests on a
premise that no longer measures true. Implementing the list as written would mean
"fixing" a glyph colour that is already correct, and replacing a focus ring that
passes its bar. This project has already had to correct one stale planning
premise (the Phase 21 release-target); catching this one before it costs work is
the cheaper version of that lesson.
Output: a re-scoped phase with measurements attached.

**`autonomous: false`** — criteria 3 and 4 are judgements about how the editor
feels, which is not something a contrast calculation settles.
</objective>
